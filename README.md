# GORIpoly

Personalizowana wersja Monopoly Deal na wieczór kawalerski Bartka Goraja.

**Strona z kartami:** https://ziarnooo.github.io/goripoly-x7k2m9/

## Co tu jest

- `index.html` - wszystkie 110 kart, do przeglądania na telefonie
- `KARTY.md` - ta sama lista w formie tekstowej, do wygodnego edytowania
- `goripoly-brief.md` - brief projektowy (ton, kolory, wymogi druku)
- `archiwum/` - pierwsza wersja porownania oryginal vs GORIpoly

## Jak dorzucic swoje uwagi

1. Otworz [Issues](../../issues/new) i wal prosto z mostu: ktora karta, co zmienic, jaki zart w zamian.
2. Albo edytuj `KARTY.md` i wyslij pull request.

Zasada projektu: mechanika, wartosci i liczba kart 1:1 jak w oryginalnym Monopoly Deal. Podmieniamy tylko nazwy i podpisy.
